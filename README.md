# ts-and-cmd

## 安装

```sh
brew install tbtsfastad/tools/ts-and-cmd
```

## 使用

在 Android 工程根目录执行。

```sh
ts-and-cmd run                  # Release，第一台可用设备
ts-and-cmd run xxxx             # Release，指定设备
ts-and-cmd run --debug          # Debug，第一台可用设备
ts-and-cmd run --debug -d xxxx  # Debug，指定设备
ts-and-cmd run --help           # 查看用法
```
